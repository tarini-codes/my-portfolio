## Projects featured

### SocialMediaPlanner
A multi-user social media post scheduler built with Spring Boot, PostgreSQL and Docker. A background scheduler publishes posts automatically to Telegram, and post ownership is enforced on the server.
- [Live demo](https://social-media-planner-6.onrender.com/login)
- [GitHub repo](https://github.com/tarini-codes/social-media-planner)

### Spring Boot Login Demo
A secure REST API with JWT authentication, role-based access control, brute-force protection and Swagger documentation.
- [Live demo](https://spring-boot-login-demo.onrender.com)
- [API docs](https://spring-boot-login-demo.onrender.com/swagger-ui/index.html)
